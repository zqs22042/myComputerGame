## AdManager 实现

```javascript
class AdManager {
  constructor() {
    this.adUnits = {
      revive: 'adunit-xxxx1',
      doubleReward: 'adunit-xxxx2',
      refreshUpgrade: 'adunit-xxxx3',
      offline: 'adunit-xxxx4',
    };
    this.ads = {};
    this.init();
  }
  init() {
    Object.keys(this.adUnits).forEach(key => {
      const ad = wx.createRewardedVideoAd({ adUnitId: this.adUnits[key] });
      ad.onError(err => console.error(`[Ad:${key}]`, err));
      this.ads[key] = ad;
    });
  }
  show(adKey) {
    return new Promise((resolve, reject) => {
      const ad = this.ads[adKey];
      if (!ad) return reject(new Error('ad not found'));
      const onClose = (res) => {
        ad.offClose(onClose);
        resolve((res && res.isEnded) || res === undefined);
      };
      ad.onClose(onClose);
      ad.show().catch(() => ad.load().then(() => ad.show()).catch(reject));
    });
  }
}
export default new AdManager();
```

## 使用

- 复活：`await AdManager.show('revive')`，成功后回血 40% 并清屏。
- 双倍结算：`await AdManager.show('doubleReward')`，成功后结算金币 ×2。
- 升级刷新：`await AdManager.show('refreshUpgrade')`，成功后重抽三选一。
- 离线收益：`await AdManager.show('offline')`，成功后离线金币 ×2。
