# 05-02 · 埋点事件清单

> 模块：05 数据与调优 ｜ 索引：[README](../README.md)

## 事件清单

| 事件名 | 触发时机 | 携带参数 | 用途 |
|---|---|---|---|
| `run_start` | 本局开始 | `rng_seed` | 复现与分组 |
| `wave_start` | 每波开始 | `wave_index`, `cycle_index`, `hp_percent` | 波次流失分析 |
| `upgrade_pick` | 升级选择 | `upgrade_id`, `line`, `level`, `cost` | 升级分布分析 |
| `upgrade_refresh` | 刷新升级项 | `method`（coin/ad）, `line` | 刷新需求 |
| `weapon_buy` | 武器槽购买/更换/拆除 | `weapon_id`, `slot`（left/right）, `cost_gold`（拆除为负值） | 武器偏好与金币出口 |
| `char_weapon_buy` | 角色武器购买解锁 | `weapon_id`, `cost_gold` | 角色武器偏好 |
| `char_weapon_upgrade` | 角色武器升级 | `weapon_id`, `level`（升后等级）, `cost_gold` | 升级节奏与金币沉淀 |
| `char_weapon_switch` | 角色武器切换携带 | `weapon_id`, `level` | 携带偏好与切换频率 |
| `screen_clear` | 清屏触发 | `kill_count`, `clear_level` | 爽感验证 |
| `crit_kill` | 暴击击杀 | `damage`, `target_type` | 打击感验证 |
| `kill` | 普通怪物击杀 | `monster_id`, `gold_drop`, `wave_index` | waves[] 每波击杀与金币聚合 |
| `boss_phase` | Boss 阶段切换 | `boss_id`, `phase`, `phase_duration` | Boss 难度曲线 |
| `boss_skill` | Boss 阶段内技能事件按时序触发 | `boss_id`, `phase`, `skill_id`, `param`, `warning` | 03-05 时序验收 |
| `cycle_end` | Boss 击杀进入下一循环 | `cycle_index`, `survival_time`, `kill_count` | 循环节奏 |
| `leak` | 漏怪 | `monster_id`, `leak_damage`, `core_hp_left` | 拦截压力 |
| `run_end` | 核心被摧毁 | `survival_time`, `cycle_index`, `kill_count`, `wave_index` | 结算与排名 |
| `ad_trigger` / `ad_click` / `ad_complete` / `ad_abandon` | 广告漏斗 | `ad_type` | 广告渗透 |
| `log_export` | 导出本局日志 | `result`, `duration_sec` | 试玩数据收集 |

## 与原埋点的差异

- `level_start` → `run_start`（无尽模式无关卡概念）。
- `level_end` → `run_end`，结果固定为 `defeat`，新增 `survival_time`、`cycle_index`。
- 新增 `cycle_end`、`boss_skill`、`upgrade_pick`、`upgrade_refresh`、`weapon_buy`、`char_weapon_buy`、`char_weapon_upgrade`、`char_weapon_switch`。
- 原 `card_pick` 改为 `upgrade_pick`。
