# 05-01 · 核心指标定义

> 模块：05 数据与调优 ｜ 索引：[README](../README.md)

## 核心指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 单局时长 | 从开始到核心被摧毁 | 3–8 分钟 |
| 首次死亡波次 | 核心被摧毁时的波次编号 | 记录基线 |
| 循环数 | 击杀 Boss 次数 | 记录基线 |
| 升级选择分布 | 装备/技能/大招三条线的选择频次 | 无一项 <5% 或 >40% |
| 广告渗透率 | 观看至少 1 次激励视频的用户 / DAU | ≥50% |
| 复活使用率 | 触发复活弹窗后观看广告的比例 | 25–35% |
