# 《孤军守卫》微信小游戏开发文档

> 竖屏单手操作的“纵向路径拦截 + 金币成长 + 循环 Boss”休闲射击小游戏，单局 3–8 分钟，核心被摧毁时按存活时间排名。

## 目录结构

- `01-产品与设计/`：产品定位、核心玩法、操作与波次、金币成长、角色武器升级系统、养成、变现、技术、里程碑、风险、脑图、技能、结算、引导、UI、技术验证、打击感、节奏曲线
- `02-数值与配置/`：升级系统设计原则、三条成长线专精、升级刷新规则、武器槽列表，以及可直接导入的 CSV 配置表
- `03-Boss设计/`：Boss 通用框架、碎骨者（MVP）、Boss 2/3 设计（后续）、阶段事件时序
- `04-商业化/`：广告点位、微信激励视频接入代码、广告设计约束、IAP 商品
- `05-数据与调优/`：核心指标、埋点事件、分析看板、首周调优节奏、本局日志导出规范、长局验证记录

## 阅读与使用建议

1. 新成员先读 `01-01` → `01-03` 建立产品与玩法全貌，再读 `01-04` 理解金币的三个出口（角色武器 + 武器槽 + 三条升级线）与 `01-18` 武器等级规则，最后看 `01-14` 对照示意图确认空间布局。
2. 策划用 `02-01` 评审升级线设计，用 `csv/` 直接配表。
3. Boss 策划从 `03-01` 开始，碎骨者是 MVP 唯一 Boss。
4. 客户端按 `04-02` 接广告，数据侧按 `05-02` 建埋点。
5. 试玩调参看 `01-17` 节奏曲线与 `05-04` 首周调优节奏，只动 `endless_config` / `upgrade_*` / `char_weapons` / `weapons` / `monsters` 五张表。
