# 03-05 · Boss 阶段事件时序

> 模块：03 Boss 设计 ｜ 索引：[README](../README.md)

碎骨者的完整阶段事件时序见 `csv/boss_phase_events.csv`，技能参数见 `csv/boss_skill_timeline.csv`。

## 单循环时长

一轮 Boss 战约 **21 秒**：P1 7 秒、P2 8 秒、P3 6 秒。阶段时长下限生效，到点才转阶段；血量提前打空不会跳阶段。

## 各阶段时序

| 阶段 | 时长 | 阶段内事件（秒） |
|---|---|---|
| P1 | 7s | 0 转场无敌；1.0 / 4.0 / 7.0 三次 `BS01_charge` |
| P2 | 8s | 0 转场；0.9 `BS02_bonespike`(3)；2.7 `BS01_charge`；4.4 `BS02`(3)；6.2 `BS01_charge`；8.0 `BS02`(3) |
| P3 | 6s | 0 转场（狂暴）；0.8 `BS01_charge`；2.0 `BS02`(5)；2.4 `BS01_charge`；4.0 `BS01_charge`；4.2 `BS02`(5)；5.6 `BS01_charge`；6.0 `BS02`(5) |

## 关键事件

- 每个阶段开头 `transition` 事件：转场 1.5s 无敌，重置技能冷却。
- Boss 驻留在防线前的固定点位（路径 y=0.68），不沿路径前进，也不对核心造成伤害。
- P1：仅 `BS01_charge`，间隔 3s。
- P2：`BS01_charge` 与 `BS02_bonespike`（3 个骨刺，0.8s 预警）交替。
- P3：`BS01_charge` 间隔降至 2s、前摇 1.0s；`BS02_bonespike` 增至 5 个、预警 0.6s，频率提高。

## 字段说明（`boss_phase_events.csv`）

| 字段 | 说明 |
|---|---|
| boss_id | Boss 唯一 ID |
| phase | 阶段（1/2/3） |
| event_time | 阶段内事件触发时间（秒） |
| event_type | transition / skill |
| skill_id | 技能 ID（对应 `boss_skill_timeline.csv`） |
| param | 技能参数（如骨刺数量） |
| warning | 预警时间（秒） |
| note | 备注 |
