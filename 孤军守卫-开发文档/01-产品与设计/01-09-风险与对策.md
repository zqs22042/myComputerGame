# 01-09 · 风险与对策

> 模块：01 产品与设计 ｜ 索引：[README](../README.md)

## 风险清单

| 风险 | 对策 |
|---|---|
| 循环节奏单调 | Boss 循环加成 + 怪物类型随循环变化 |
| 金币升级同质化 | 三条线各有专精方向，避免“永远升攻击力” |
| 存活时间方差大 | 调 `hp_step_growth` / `boss_wave_step_extra`，保证 3–8 分钟区间 |
| 排行榜作弊 | MVP 先本地记录，接入微信排行榜时用开放数据域校验 |
| 广告打断节奏 | 所有广告点主动触发，单局上限 3 次 |
| 单路径 + 缩小人物活动区导致走位空间小 | 路径分窄通道与加宽段形成远近层次；活动区横向覆盖整个站位区，靠左右偏置取舍；操作深度由左右武器槽购买与三条线升级补足 |
| 武器槽付费墙过重 | 最短 120 金即可生效，且武器吃装备线加成；空槽用虚线 + 价格常驻提示 |
