# 01-01 · 产品定位与概述

> 模块：01 产品与设计 ｜ 索引：[README](../README.md)

## 一句话定位

竖屏单手操作的“纵向路径拦截 + 金币成长 + 循环 Boss”休闲射击小游戏。怪物从画面顶部沿纵向路径向下推进，玩家在站位区下部的人物活动区内移动拦截，并用金币在核心左右武器槽购买武器、升级装备/技能/大招，每循环 10 波以 Boss 收尾并直接进入下一循环，核心被摧毁时按存活时间排名。

## 基本信息

| 项目 | 内容 |
|---|---|
| 游戏名（暂定） | 孤军守卫 |
| 平台 | 微信小游戏（优先），预留抖音小游戏移植 |
| 品类 | 休闲射击 / 单路径拦截 / 金币成长 / 循环 Boss |
| 核心循环 | 拦截 → 击杀得金币 → 购买武器 / 升级三条线 → 每 10 波 Boss → 进入下一循环 → 核心被摧毁 → 按存活时间排名 |
| 单局时长 | 3–8 分钟（取决于存活时间） |
| 操作方式 | 竖屏，单手拖拽角色在人物活动区内移动，角色朝上自动开火；点击左右武器槽购买武器 |
| 变现模型 | IAA 为主（复活/双倍/刷新）+ 轻 IAP（去广告、月卡、皮肤） |
| 目标用户 | 25–45 岁碎片时间玩家，偏男性，接受过《向僵尸开炮》类产品教育 |

## 核心体验支柱

1. **简单操作**：拖拽移动 + 自动开火，决策集中在“站位、先买武器还是先升级、何时放大招”。
2. **爽快清屏**：金币买下左右武器、三条线成型后，路径被交叉火力覆盖，怪物成片倒下。
3. **每局不同**：武器购买顺序 + 升级选择 + 循环 Boss 血量递增，形成“撑多久”的排名驱动。

## 与原塔防版的差异

| 要素 | 原塔防版 | 新玩法 |
|---|---|---|
| 炮台/建塔 | 有，任意节点建造 | **仅核心左右两个固定武器槽，金币购买** |
| 路径 | 多节点固定路径 | **纵向单条路径，顶部刷怪、底部加宽，带防线** |
| 角色位置 | 沿路径节点移动 | **站位区下部的人物活动区（缩小矩形）** |
| 失败条件 | 核心归零 | **核心归零**（保留） |
| 成长方式 | 肉鸽词条堆叠 | **金币购买武器 + 升级装备/技能/大招** |
| 关卡结构 | 多关 8–12 波 | **唯一一关，循环无限，每循环 10 波** |
| 结束条件 | 通关或失败 | **核心被摧毁** |
| 结算 | 三星评价 | **按存活时间排名** |
