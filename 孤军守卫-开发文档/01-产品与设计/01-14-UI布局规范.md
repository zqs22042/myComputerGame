# 01-14 · UI 布局规范

> 模块：01 产品与设计 ｜ 索引：[README](../README.md)

> 以 `手机游戏示意图.png` 为准：纵向刷怪路径 → 防线 → 玩家站位区（核心 + 左右武器槽 + 人物活动区）。

## 设计分辨率

750 × 1334，竖屏，SHOW_ALL。

## 空间结构（自上而下）

1. **顶部 HUD**：核心血量条、循环数 + 波次、金币数、存活时间与击杀数（浮在战场上方，不占独立横条）。
2. **战场（草地区）**：纵向单路径，怪物从画面顶部中央的**刷怪点**出现，沿路径向下推进；接近防线时路径**加宽**，怪物横向散开。
3. **防线**：横跨战场的红色横线，是玩家可拦截的最后边界；越线怪物继续冲向核心，抵达核心即判漏怪。
4. **玩家站位区**：石墙围合的平台，位于防线下方。区内包含：
   - **我方核心**：平台中央的蓝色光球，核心血量归零即失败。
   - **左侧武器部署区 / 右侧武器部署区**：核心左右各 1 个武器槽，金币购买后放入，自动朝路径开火。
   - **人物活动区**：平台下部缩小后的蓝色矩形，角色只能在此区域内移动。
5. **底部操作栏**：装备 / 技能 / 大招三个升级图标 + 主动技、大招按钮。

## 视觉要点

- 地面：草地 + 土黄色路径，站位区为深灰石台，边界用亮蓝描边标示人物活动区。
- 核心：蓝色发光球体 + 外圈弧光；血量下降时颜色转黄、转红。
- 武器槽：空槽为虚线底座 + 价格文字，已放置显示武器外观与名称。
- 角色：位于人物活动区内，**朝上（朝防线）自动开火**，携带当前选中武器（初始为基础步枪）；子弹形态随武器变化——白色小圆弹 / 橙黄弹丸 / 蓝色光束 / 红色导弹。
- 怪物：顶部沿路径向下推进；越过防线后加红色描边，提示玩家已来不及拦截。

## 渲染层级

草地/路径 → 防线 → 站位区地台 → 核心 → 武器 → 怪物 → 角色 → 子弹/特效 → HUD → 弹层。

## 弹层

- **角色武器面板**：点击操作栏武器图标弹出，顶部为武器选择栏（4 把武器图标横排：携带中高亮、未解锁加锁显价格、满级右上角【MAX】），下方为【购买武器】【升级】按钮；升级成功播放弹窗文字 + 闪光 + 音效，满级升级按钮置灰。详见 [01-18](01-18-角色武器升级系统.md)。
- **武器购买**：点击武器槽弹出，列出 `weapons.csv` 中的武器（价格、伤害、射速），金币不足置灰；已放置时提供「替换」与「拆除（返还 50%）」。
- **升级三选一**：居中，半透明遮罩，三张卡片，选中后立即关闭。
- **暂停**：右上角暂停按钮。
- **结算**：居中面板，存活时间、循环数、击杀数、波次数、最高连击；底部「再来一局」「导出本局日志」。

## 触摸热区

- 人物活动区高度约屏高 18%，位于底部拇指可及范围，拖拽不遮挡路径与防线。
- 武器槽点击区域 ≥ 96×96px，左右对称。
- 升级图标三枚横向排列于操作栏，间距均匀。
- 武器图标位于操作栏升级图标旁，点击热区 ≥ 96×96px；武器面板内武器图标热区 ≥ 88×88px，加锁态同样可点（弹购买确认）。
- 技能按钮在右下拇指热区，直径 ≥48px。
