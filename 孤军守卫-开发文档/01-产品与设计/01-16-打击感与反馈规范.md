# 01-16 · 打击感与反馈规范

> 模块：01 产品与设计 ｜ 索引：[README](../README.md)

## 设计目标

割草游戏的爽感 70% 来自反馈。本规范定义“命中 → 击杀 → 清屏 → Boss 受击”四层反馈的参数，作为程序与美术的接口约定。所有参数均为可配置项，MVP 阶段给默认值，后续按试玩手感调。

## 一、命中反馈

### 1.1 命中停顿（Hitstop）

| 场景 | 停顿时长 | 说明 |
|---|---|---|
| 普通命中 | 0.02s | 极短，仅让子弹有“咬住”感 |
| 暴击命中 | 0.05s | 可感知的顿挫 |
| 击杀 | 0.06s | 与命中叠加，上限 0.08s |
| 连锁爆炸触发 | 0.04s/次，单帧最多 2 次 | 防止高频爆炸导致卡顿 |

**实现约束**：停顿时长作用于命中目标与子弹，不冻结全局时间；Boss 阶段转场期间不触发停帧。

### 1.2 屏幕震动

| 场景 | 幅度（像素） | 时长 | 频率 |
|---|---|---|---|
| 普通命中 | 0 | — | 不震 |
| 暴击 | 2 | 0.08s | 单次 |
| 击杀精英 | 4 | 0.12s | 单次 |
| 爆炸 | 3 | 0.10s | 每爆炸一次 |
| Boss 冲撞命中核心 | 8 | 0.20s | 单次 |
| 核心血量 ≤20% | 持续 1px 抖动 | 常驻 | 低频呼吸式 |

**约束**：同帧多次震动取最大值，不叠加；震动不影响 UI 层。

### 1.3 受击闪白与击退

- 怪物受击闪白 0.06s，颜色 `#FFFFFF` 叠加 60% 透明度。
- 普通怪击退 8px，精英 4px，Boss 不击退。
- 击退方向沿子弹飞行方向，不做物理模拟。

## 二、击杀反馈

### 2.1 死亡表现分层

| 怪物类型 | 死亡表现 | 时长 |
|---|---|---|
| 快速小怪 M01 | 碎裂为 4–6 个色块粒子，向四周飞散 | 0.3s |
| 装甲怪 M02 | 装甲片剥落 + 内部核心爆开 | 0.4s |
| 飞行怪 M03 | 向下坠落 + 拖尾消散 | 0.35s |
| 自爆怪 M04 | 原地爆炸（不伤玩家），范围 80px | 0.4s |
| 精英盾卫 M05 | 装甲全碎 + 慢动作 0.15s + 金色粒子 | 0.6s |
| Boss | 阶段转场动画 + 最终死亡大爆炸 | 1.5s |

### 2.2 击杀音效分层

| 场景 | 音效层 | 音量 | 说明 |
|---|---|---|---|
| 普通击杀 | 短促“噗”声 | 60% | 同帧多次击杀只播 2–3 次，避免噪音 |
| 暴击击杀 | 金属“叮”+ 低频“咚” | 75% | 与普通击杀叠加 |
| 连锁爆炸 | 低频“轰”+ 碎片声 | 80% | 每次爆炸独立播放，上限 3 次/秒 |
| 精英击杀 | 专属击杀音 + 短暂静音 0.1s | 85% | 静音制造“重量感” |
| Boss 阶段切换 | 转场音 + 低频轰鸣 | 90% | 与转场动画同步 |

**约束**：同帧同类音效超过 3 次时合并为一次播放，音量 +10%。

### 2.3 伤害数字

- 普通伤害：白色，字号 24，上飘 40px，0.5s 淡出。
- 暴击伤害：黄色 `#FFD700`，字号 32，带 1.2 倍缩放弹跳，上飘 60px，0.6s 淡出。
- 持续伤害（灼烧/毒雾）：橙色，字号 18，每 0.5s 跳一次，不弹跳。
- 同目标同帧多个伤害数字合并显示总和，避免刷屏。

## 三、清屏反馈

清屏定义为**单帧内击杀 ≥8 只怪物**或**单次技能击杀 ≥15 只**。

### 3.1 清屏触发表现

| 层级 | 触发条件 | 表现 | 参数 |
|---|---|---|---|
| 轻清屏 | 8–14 杀 | 屏幕边缘轻微白闪 + 短促“唰”声 | 白闪 0.1s，透明度 20% |
| 中清屏 | 15–29 杀 | 全屏白闪 + 慢动作 0.1s + 低频轰鸣 | 白闪 0.15s，透明度 35% |
| 重清屏 | ≥30 杀 | 全屏白闪 + 慢动作 0.2s + 镜头拉远 5% + 专属音效 | 白闪 0.2s，透明度 50% |

**约束**：慢动作仅作用于怪物与子弹，UI 与技能冷却不受影响；重清屏每分钟最多触发 2 次，防止视觉疲劳。

### 3.2 粒子密度上限

- 普通战斗：同屏粒子 ≤ 300。
- 清屏瞬间：同屏粒子 ≤ 600，持续 0.5s 后回落。
- 低端机降级：粒子数减半，保留白闪与慢动作，砍掉碎片粒子。

## 四、Boss 受击反馈

| 场景 | 表现 |
|---|---|
| 普通受击 | 闪白 0.06s + 伤害数字，不击退 |
| 暴击受击 | 闪白 + 黄色数字 + 2px 震动 |
| 阶段切换 | 全屏暗角 + 转场动画 1.5s + 低频轰鸣，期间 Boss 无敌且不显示伤害数字 |
| 濒死（血量 ≤10%） | Boss 身体持续红光脉冲，频率随血量降低加快 |
| 死亡 | 慢动作 0.5s + 全屏白闪 + 大爆炸粒子 + 结算音效 |

## 六、与埋点的关系

在 `05-02-埋点事件清单.md` 基础上补充三个事件：

| 事件名 | 触发时机 | 参数 |
|---|---|---|
| `screen_clear` | 清屏触发 | `kill_count`, `clear_level`（light/mid/heavy） |

## 七、角色武器音效与升级反馈

角色武器系统（见 [01-18](01-18-角色武器升级系统.md)）的专属反馈参数：

### 7.1 武器音效

| 武器 | 音效 | 说明 |
|---|---|---|
| RW01 基础步枪 | 清脆「砰」 | 等级越高音效更厚重（音调降低 + 音量 +5%/级） |
| RW02 霰弹枪 | 低沉轰鸣 | 低频占比高 |
| RW03 激光枪 | 高频嗡鸣 | 持续音随发射截断 |
| RW04 追踪导弹 | 发射呼啸声 + 爆炸轰鸣声 | 爆炸音遵循 2.2 节连锁爆炸上限 |

### 7.2 升级与购买反馈

| 场景 | 表现 |
|---|---|
| 武器升级成功 | 弹窗文字 + 闪光特效 + 正向提示音，武器枪身外观变化（配件增加 / 发光增强） |
| 购买解锁 | 解锁音效 + 图标加锁动画解除 |
| 满级 | 右上角【MAX】标识，升级按钮置灰，不再播放升级音 |

### 7.3 武器切换

- 切换武器即时换弹形（子弹形态随武器变化），播放短促切换音（0.1s），不触发停顿与震动。

## 八、MVP 阶段取舍

- **必须做**：命中停顿、暴击数字、击杀粒子、清屏白闪、Boss 阶段转场。
- **可后置**：屏幕震动（先用固定幅度）、慢动作（先用 0.1s 统一值）、专属击杀音效（先用免费音效占位）。
- **不做**：物理击退模拟、伤害数字合并的复杂算法、按设备分级的粒子 LOD（MVP 统一用低配档）。
