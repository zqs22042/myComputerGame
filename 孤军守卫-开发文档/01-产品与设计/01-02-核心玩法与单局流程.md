# 01-02 · 核心玩法与单局流程

> 模块：01 产品与设计 ｜ 索引：[README](../README.md)

## 单局流程

```
开始 → 循环 1 第 1 波怪物从画面顶部刷怪点沿纵向路径向下推进
→ 角色在人物活动区（站位区下部缩小后的蓝色矩形）内移动，朝上自动索敌开火
→ 怪物临近防线时路径加宽、横向散开；越线后继续冲向核心
→ 击杀获得金币 → 金币出口：升级角色武器（购买/升级/切换，弹数随等级 1/3/5/7）/ 购买左右武器槽武器 / 升级装备·技能·大招三条线；角色武器满级后，溢出金币转为局内软成长
→ 第 1–4 波普通 → 第 5 波精英 → 第 6–9 波普通 → 第 10 波 Boss
→ Boss 击杀 → 直接进入循环 2（波次编号继续递增）
→ 循环 N：怪物血量每 5 波跳一档，Boss 波额外跳档；满级后溢出金币持续换软成长
→ 核心被摧毁 → 按存活时间结算排名
```

## 三层结构

- **拦截层（空间决策）**：纵向单路径 + 防线 + 玩家站位区。防线是最后拦截边界，站位区内核心居中、左右各一个武器槽，人物活动区缩小在站位区下部。角色站位决定射程覆盖路径哪一段，左右武器提供不依赖操作的额外火力，核心是唯一失败条件。
- **成长层（金币驱动）**：击杀获得金币，金币有三个出口——升级角色武器（购买解锁霰弹/激光/导弹并逐级升到 Lv4，火力主干）、一次性购买左右武器槽的武器（立即可见的火力质变），以及在局内三选一升级装备、技能、大招三条线（逐级叠加强度）。
- **压力层（波次台阶 + 循环驱动）**：普通怪血量每 5 波跳一档，Boss 波额外跳档；角色武器满级后溢出金币可换局内软成长（伤害/射速，边际递减并封顶），循环无限，玩家最终仍会被递增的数量与台阶压垮。

## 结束与结算

- 结束：核心血量归零，本局结束。
- 结算：显示存活时间、循环数、击杀数、波次数、最高连击。
- 排行榜：好友排行 + 全服排行，按存活时间降序；同存活时间按循环数降序。

## 设计意图

循环无限 + 每轮 Boss 收尾 + 按存活时间排名，把“通关”变成“撑多久”，用排行榜驱动重复挑战。Boss 击杀即进入下一循环，不打断节奏，保证玩家始终处于“下一轮马上来”的压力中。
