# 01-18 · 角色武器升级系统

> 模块：01 产品与设计 ｜ 索引：[README](../README.md)

> 本系统定义**角色主武器**的解锁、升级、切换与子弹行为。数值配置见 `02-数值与配置/csv/char_weapons.csv`。
> 与左右武器槽的关系：**只改角色武器**，核心左右固定武器部署区维持原设计（`weapons.csv` 三种槽位武器，一次性购买、无等级，见 [01-04](01-04-金币成长系统.md)），两套体系互不影响。

## 系统边界（拍板结论）

| 决策点 | 结论 |
|---|---|
| 进度归属 | 局内金币驱动，本局内解锁 + 升级，局结束清零 |
| 射击触发 | 保持自动开火：拖拽移动，冷却结束自动发射；弹数 = 武器当前等级，节奏 = 射击间隔 |
| 部署区 | 左右固定武器部署区不改；本系统只作用于角色携带的武器 |

## 一、系统 UI 面板

点击操作栏的**武器图标**打开武器升级面板（暂停式弹层，与升级三选一一致）：

- **武器选择栏**：横向排列 4 把武器图标
  - 当前选中（角色携带中）武器高亮展示，带「携带中」角标
  - 未解锁武器图标加锁，显示购买价格
  - 已解锁未携带武器正常显示，点击即切换携带
- **【购买武器】按钮**：选中未解锁武器时可用，消耗金币解锁；金币不足置灰
- **【升级】按钮**：对当前选中武器升级，消耗金币；满级按钮置灰，不可点击
- **MAX 标识**：满级武器右上角显示【MAX】

## 二、通用等级规则（所有武器共用）

- **等级 − 单次发射子弹数量**：Lv1 = 1 发，Lv2 = 3 发，Lv3 = 5 发，Lv4 = 7 发（等级上限，无法继续升级）。
- **升级同步增益**：等级提升时，射击间隔缩短（射速↑）、单发伤害提升。
- **养成规则**：各武器等级**独立**，互不共享；切换武器自动加载该武器已养成等级与属性。

## 四、资源经济逻辑

- **购买武器**：一次性消耗金币，本局内永久解锁，随时切换携带（局结束清零，下一局回到初始基础步枪 Lv1）。
- **武器升级**：单武器独立升级，消耗随等级递增：

| 升级段 | 消耗 |
|---|---|
| Lv1 → Lv2 | 金币 × 50 |
| Lv2 → Lv3 | 金币 × 120 |
| Lv3 → Lv4 | 金币 × 250 |

- **资源获取途径**（XMind「击杀敌人、通关关卡、完成挑战」在本作的映射）：
  - 击杀敌人：击杀怪物掉落金币（主途径，`monsters.csv` 的 `gold_drop`）。
  - 通关关卡 → 无尽模式映射为**击败 Boss 进入下一循环**（Boss 高额金币掉落）。
  - 完成挑战 → 原型阶段后置，预留波次里程碑奖励接口。

## 五、战斗逻辑与子弹碰撞判定

- **基础射击机制**：角色按武器射击间隔自动发射，单次发射子弹数量 = 武器当前等级；冷却未结束时不再发射。
- **武器切换逻辑**：切换武器自动加载该武器已养成等级与属性，切换不重置射击冷却。
- **吃装备线加成**：角色武器的伤害、射速、射程、穿透享受装备线百分比加成（与三条线共用同一套 `bonuses`）。

### 子弹生命周期

1. **生成**：发射瞬间生成对应数量子弹实体（1/3/5/7 发）。
2. **移动**：按武器类型执行运动——直线（步枪）/ 扇形散射（霰弹）/ 光束穿透（激光）/ 追踪锁定（导弹）。
3. **碰撞判定**：
   - **步枪**：子弹碰到敌人触发伤害；碰撞后子弹销毁，不可穿透。
   - **霰弹枪**：每个弹丸独立判定，远距离伤害衰减；碰到敌人销毁。
   - **激光**：光束碰到敌人扣血，可穿透指定数量敌人，穿透上限耗尽后消失。
   - **追踪导弹**：命中敌人 / 地面触发爆炸，爆炸范围内所有目标受到伤害；导弹本体销毁。
4. **超时销毁**：子弹超过最大飞行时间 / 最大飞行距离自动销毁，防止内存占用（对象池回收）。

### 多子弹命中规则（重点）

> 单次发射 3/5/7 发子弹，**每一颗子弹独立做碰撞检测**，可以同时命中同一个敌人，也可以分散命中多个敌人。
> 例：霰弹枪 Lv2 一次射出 3 颗弹丸，3 颗全部命中同一个敌人，则 3 次伤害叠加。

### 伤害计算

```
最终伤害 = max(1, 子弹伤害 × 装备线攻击加成 - 敌人 armor)
```

- 敌人防御取 `monsters.csv` 的 `armor` 字段；最小伤害保底 1。
- **霰弹衰减**：弹丸伤害随飞行距离线性衰减，最远射程处伤害为近点的 50%（衰减系数可调，初值待调参）。
- **爆炸伤害**：= 单发伤害，半径内所有目标各结算 1 次。

### 敌人受击规则

- 单次射击多颗子弹：每颗子弹独立判定命中，伤害叠加。
- 受击反馈：敌人播放受击动画、血条扣减、受击粒子特效、屏幕震动——参数遵循 [01-16 打击感与反馈规范](01-16-打击感与反馈规范.md)。

## 六、边界限制（防 BUG）

1. **导弹爆炸伤害不叠加**：同一发导弹爆炸，单个敌人只受到 1 次爆炸伤害，不会多次扣血。
2. **激光穿透计数**：每穿过 1 个敌人，穿透计数 −1，计数为 0 激光消失。
3. **子弹数量上限硬编码**：任何逻辑（含装备线加成）不能突破 7 发上限。

## 七、表现与 UI 反馈

- **武器外观变化**：每提升一级，枪身增加配件 / 发光强度提升。
- **升级成功反馈**：弹窗文字 + 闪光特效 + 音效。
- **状态提示**：满级武器右上角显示【MAX】标识。
- **音效清单**：

| 场景 | 音效 |
|---|---|
| 步枪 | 清脆「砰」；等级越高音效更厚重 |
| 霰弹枪 | 低沉轰鸣 |
| 激光枪 | 高频嗡鸣 |
| 追踪导弹 | 发射呼啸声 + 爆炸轰鸣声 |
| 升级成功 | 正向提示音 |
| 购买武器 | 解锁音效 |

## 八、系统限制规则

- 单武器等级上限 Lv4，满级升级按钮置灰、无法点击。
- 未购买武器：图标锁定，不可选中、不可升级。
- 射击冷却：受射速控制，冷却未结束时点击射击无效（自动开火下表现为冷却期间不发射）。
