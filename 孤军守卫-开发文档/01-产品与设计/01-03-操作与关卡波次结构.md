# 01-03 · 操作与波次结构

> 模块：01 产品与设计 ｜ 索引：[README](../README.md)

> 空间结构以 `手机游戏示意图.png` 为准：纵向路径 → 防线 → 站位区（核心 + 左右武器槽 + 人物活动区）。

## 操作设计（单手竖屏）

- **主操作**：手指拖拽角色在**人物活动区**（站位区下部缩小后的蓝色矩形）内移动，角色**朝上（朝防线方向）自动索敌开火**——携带当前选中武器，单次发射弹数 = 武器等级（1/3/5/7 发），节奏 = 武器射击间隔（见 [01-18](01-18-角色武器升级系统.md)）。
- **角色武器操作**：点击操作栏武器图标打开武器面板——选择栏切换携带武器（切换自动加载该武器等级）、【购买武器】解锁新武器、【升级】提升当前武器等级（满级置灰）。
- **武器槽操作**：点击核心左右两个武器槽，用金币购买武器并放置；槽位已有武器时可替换或拆除（返还 50%）。
- **副操作**：底部两个技能按钮（主动技 + 大招），冷却制。
- **升级操作**：金币足够时，点击装备/技能/大招图标弹出三选一，暂停式选择。
- **设计原则**：活动区域缩小并放在底部拇指热区，手指拖拽不遮挡路径与防线；决策重心从“跑到哪”转为“先买武器还是先升级”。

## 地图结构（唯一一关）

纵向单路径，自上而下分四段：

1. **刷怪点**：画面顶部中央，怪物从这里出现。
2. **纵向通道**：宽约屏宽 16%，怪物单列向下推进。
3. **加宽段**：临近防线时路径张开，怪物横向散开，拦截难度上升。
4. **防线**：横跨战场的红线，是最后拦截边界；越线怪物继续冲向核心。

防线下方是**玩家站位区**：

- **我方核心**：站位区中央，有独立血量条，是唯一失败条件。
- **左侧 / 右侧武器部署区**：核心左右各 1 槽，金币购买武器后自动开火。
- **人物活动区**：站位区下部的小矩形，角色只能在此移动，不能越线进入路径。

## 波次结构（循环无限，每循环以 Boss 收尾）

- 无尽模式按**循环**推进，每个循环固定 10 波：
  - 第 1–4 波：普通波，怪物类型按 `spawn_weight` 随机。
  - 第 5 波：精英波，必出精英盾卫。
  - 第 6–9 波：普通波，数量继续增长，血量进入下一档。
  - 第 10 波：Boss 波，出碎骨者，血量额外跳档、伤害吃循环加成。
- Boss 击杀即节点结束，**直接进入下一循环**，波次编号继续递增（第 11 波开始循环 2）。
- 不暂停、不结算、无轮次奖励，节奏连续。
- 怪物血量按波次分段台阶增长（每 5 波一档），Boss 波额外跳档；满级后溢出金币转为局内软成长。

## 怪物血量增长公式

```
普通怪血量 = hp_base × (1 + hp_step_growth)^floor((波次-1) / hp_step_waves)
Boss 血量   = hp_base × (1 + hp_step_growth)^(floor((波次-1) / hp_step_waves) + boss_wave_step_extra)
Boss 伤害   = 基础伤害 × (1 + boss_damage_cycle_bonus × (循环数-1))
```

## 满级后软成长公式

当前携带的角色武器达到 Lv4 后，金币超过 `soft_growth_reserve` 的部分自动进入软成长池：

```
软成长加成 = cap × (1 - e^(-累计溢出金币 × per_gold / cap))
伤害：soft_dmg_per_gold / soft_dmg_cap
射速：soft_aspd_per_gold / soft_aspd_cap
```

边际递减、封顶；武器本体 Lv4、弹数 1/3/5/7、单发伤害与四种子弹碰撞规则均不变。

## 站位策略

人物活动区缩小后，站位差异体现在“前后”与“左右偏置”，影响覆盖与安全性：

| 站位 | 优势 | 风险 |
|---|---|---|
| 贴近防线（上沿） | 射程覆盖加宽段，提前削血 | 贴身放怪，容错低 |
| 居中（核心正前） | 覆盖稳定，左右兼顾 | 对两侧绕行怪覆盖一般 |
| 左右偏置 | 集中覆盖单侧通道 | 另一侧与 Boss 换位时照顾不到 |
| 贴近核心（下沿） | 安全，专清漏网怪 | 射程到不了加宽段，压力全压在武器 |

## 漏怪规则

- 怪物**越过防线**后仍沿路径冲向核心，抵达核心即判漏怪，按 `monsters.csv` 的 `leak_damage` 扣核心血量。
- 自爆怪漏到核心时自爆，扣更高伤害。
- 漏怪不返还金币，但保留已获得金币。
- 武器与角色火力都覆盖不到的位置，只能用技能（震荡波 / 弹幕风暴）补救。
